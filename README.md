# Higher-order adaptive Deffuant model
Code to simulate the adaptive Deffuant model with group interactions.
The notebooks reproduce the results presented in the paper "Group adaptation drives opinion dynamics in higher-order networks", C. Agostinelli, M. Mancastroppa, A. Barrat (2026).

If you use this code, please cite the paper https://arxiv.org/abs/2602.19684.
