# Higher-order adaptive Deffuant model
Code to simulate the adaptive Deffuant model with group interactions.
The notebooks reproduce the results presented in the paper "Group adaptation drives opinion dynamics in higher-order networks", C. Agostinelli, M. Mancastroppa, A. Barrat, APS Open Sience (2026).

If you use this code, please cite the paper https://doi.org/10.1103/gcz4-wwb3.
